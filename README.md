# Vox 1.4.0 · 个人聊天客户端

版本 1.4.0，build 19。最低 iOS 26；Bundle ID 保持 com.xiaolong.qingjian。

本版（藤黄）改动：
- 视觉改为黑、白加一点藤黄：冷白纸面、宋体、原生液态玻璃；随系统外观自动切换深浅。
- 每次冷启动都打开一张新的空白页，不再回到上次的对话；以前的对话都在侧栏里。
- 空白页是开场页：一轮藤黄从输入框后升起，问候语按本机时间（早上好 / 下午好 / 晚上好）和个人资料里的名字逐行出现，最后一笔荧光划过。只在新页出现时播放一次；系统开启“减弱动态效果”时不播放。
- 对话页：标题和日期做成章头，随内容滚动，点标题仍可打开侧栏；自己的话靠右、加重、没有气泡；回答在左，前面一个黄点；回答里的加粗显示为荧光笔底色。
- 侧栏改为“目录”：编号、点线、日期；当前对话用荧光标出。没有内容也没有草稿的空白页不占条目。
- 图片：加号菜单可从相册选图（每条最多 4 张），发送前缩到长边 1280 像素。只有 Flash 能读图；选 V4 Pro 时带图发送会提示切换，历史里的图片在 V4 Pro 请求中省略。每次请求只携带最近 4 条带图消息的图片。图片文件保存在本机 Application Support/QingJian/images，不随聊天备份导出；删除对话时一并删除。
- 花费：每条回答在 Token 旁显示估算花费。按官方人民币价目（2026 年 10 月核对）、请求时刻的高峰或空闲时段（北京时间周一至周五 9–12、14–18 点为高峰）和缓存命中数计算；法定节假日无法识别。旧版本保存的回答没有记录模型，不显示花费。设置的“用量”里有合计。实际扣费以 DeepSeek 开放平台为准。
- 吐字卡顿修复：流式文字先攒着，约每秒 15 次统一刷新界面；标题不再放在顶栏里随每个字重排；已完成的回答不再随新回答重复解析；去掉了根视图上的全局自定义字体。
- 标题、问候语和自己的话使用 NotoSerifSC-Bold；工程里没有这个字体文件时退回系统粗体。

沿用的能力：
- 侧栏与聊天页两层整页连续圆角；聊天内容区任意横向位置右滑展开侧栏；触感反馈可在设置关闭。
- 底部仅聊天和设置，系统原生 TabView 与 Liquid Glass；聊天列表延伸到屏幕底部，输入框与底栏悬浮覆盖。
- 设置顶部显示自己的头像、名字和 ID；资料只存本机，不包含在聊天备份中。
- 输入框思考菜单可开关思考，并直接选择轻量、标准、深入。
- 每条回答展示服务端返回的本次总 Token；不用字符数冒充 Token。
- 默认上下文 200 条，最高 400 条，超长时保留最近完整消息。
- 思考过程按需翻译，支持原文、中文、双语；译文随对话备份保存，不进入正式聊天上下文。
- 消息编辑、重新回答、历史搜索、置顶、改名与备份。

源码未包含 API Key 或签名材料。运行 scripts/build-ipa.sh 会检查结构、运行测试、使用 Xcode 26 编译并生成未签名 IPA。设置 QINGJIAN_CAPTURE_PREVIEWS=1 时从实际模拟器捕获界面，预览模式只使用虚构数据且不联网。

已有用户先导出重要聊天记录，再沿用原证书和 Bundle ID 签名覆盖安装。云端测试与模拟器截图不等同于手机上的真实 API 调用验证。

历史验证材料只描述相应旧版本。当前验证以本次 Actions 日志和安装包核验为准。

界面回归验证：UITests/NavigationUITests.swift 使用真实模拟器触摸事件检查右半屏起滑、全高纵向滚动、最后一行可读性及键盘布局。截图脚本同时导出测试附件与 xcresult 摘要。

交互回归还验证了发送新消息后的自动滚动位置。侧栏显示状态以实际可操作性判定，隐藏但留在可访问性树中的按钮不算可见侧栏。

长对话自动跟随使用系统 ScrollPosition 的底部定位，避免按末尾虚拟占位元素定位时跳入懒加载估算的空白区域。

聊天列表按实际高度布局，默认显示最近 100 条，顶部可继续查看更早消息；此显示分页不影响记录保存和 API 上下文数量。侧栏使用系统水平拖动识别器，在开始识别前排除纵向手势，避免移动页面时取消正在进行的侧栏拖动。


本轮连接与交互修复：
- 恢复真正的系统 TabView，移除替代它的自绘底部按钮；侧栏手势不截获 UITabBar 的触摸。
- 聊天区区分正在连接、等待模型、正在思考、正在回答，并显示耗时和实际收到的思考字数。
- 请求和会话均显式设置 600 秒无数据超时、1800 秒总时限；支持 DeepSeek 等待期间的 SSE keep-alive。不自动重试或降低用户的思考档位。
- 设置页增加实际对话测试：当前 Key、Flash、关闭思考、独立小请求，不发送历史聊天，会产生少量 API 用量。
- 可复制不含 Key 和正文的连接诊断，包含模型、请求参数、阶段、字节数和错误码。余额查询成功不等于实际对话已经验证。
- 从设置返回聊天不再每次强制跳到最后，保留当前阅读位置。
- 网络回归使用 URLSession + URLProtocol 固定数据验证等待、思考、输出、取消、鉴权与中断；不使用真实 Key。
- UI 回归新增实际按住并拖动原生 TabBar 在聊天和设置之间切换。

本轮历史列表修复：
- 重新生成直接替换当前对话最后一次回答，不新建对话、不添加“重试”标题。
- 编辑后保存只替换这条消息，保留后面的记录；编辑用户消息并重新发送则替换其后的内容。
- 保持当前对话 ID、名称、置顶、草稿和未修改消息的 ID 与实际用量记录。
- 旧版自动生成的分支按 parentThreadID 收拢为一个历史入口；优先显示当前正在使用的版本，其余对话选最近更新版本，去掉可确认由旧版自动添加的标题后缀。
- 不按标题合并，因此名字相同但独立建立的对话仍分别显示。旧版分支数据仍包含在导出备份中；本版重试不再创建旧回答副本。
- 删除一个已收拢对话时同时删除其旧版关联分支，避免删除后旧条目重新出现；删除前仍有应用内确认。
- 核心测试覆盖重复重试、就地编辑、后续消息、旧分支、同名独立对话、手动改名和异常父关联；界面测试实际操作连续三次重试和编辑回答，确认列表条目不增加。


本轮键盘遮挡修复：
- 保持原来的全屏聊天与原生底栏布局，按完整输入框的实际位置修正其与键盘的重叠。
- 输入框保持自然高度，文字、菜单和发送行作为整体避让键盘；键盘收起时恢复原位。
- 使用系统键盘结束位置及当前输入控件的可见附加工具栏边界；不写死键盘高度，不读取输入内容。
- 覆盖六行输入、附加键盘区域加高和实际点击发送；测试控件只在 UI 预览模式出现。
- 微信输入法仍需用户手机上的最终复测。
