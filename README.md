Vox 1.5.0 / build 20 候选版本：仿 Claude 改版、项目、用量日历、猜你回复

基线为已交付的 1.4.0 / build 19。本目录是独立工作副本。
界面：照 Claude 客户端排版，全部宋体，陶土橙点缀，保留荧光笔高光；去掉底部标签栏，设置从侧栏左下头像进入。
输入框下一个「模型 档位」药丸（如 Flash High），档位为 Off / Low / High / Max。
项目：各自的指令（不叠加全局提示词）、可开关的资料、默认模型与档位、面容 ID 锁；项目里的对话不进「最近」。
「查看全部」可多选、全选，批量移入项目或删除；对话可导出为 Markdown。
用量：单独按天记账（回答、猜你回复、思考翻译），删除对话不影响；设置顶部为每日用量日历。
猜你回复：回答完成后给 1～3 条草稿，点选填入输入框，编辑后自己发送；项目内跟随项目指令。
旧备份与旧设置保持可解码；首次打开会从已有对话补算用量。

本机没有 Swift/Xcode：核心测试与界面测试已加入，尚待 macOS/Xcode 执行。
本目录尚未产生新 IPA，也未上传到 GitHub 或替换已发布版本。
