Sermo 1.6.0 / build 30：GitHub 工具、提示词变量、时间流逝、说明书、自定义字体

- 整合修复：补齐 GitHub 的 Combine 导入；工具在执行前及用户确认后按当前项目开关再次校验；变量只替换指令，资料和记忆原样保留；切换字体保留设置页与未保存草稿；读取网页和跟随跳转前检查 DNS 返回的全部 IPv4/IPv6 地址，拒绝私有和保留地址。
- 回归覆盖：新增工具权限、指令与资料隔离、DNS 私网与跳转的 mock 单元测试，以及切换字体保留设置草稿的 UI 测试。构建及测试结果以对应 GitHub Actions 运行记录为准。
- 字体回归核对：字体选择器明确提供当前选项的可访问性值，现有导航栏也就地更新字体；UI 测试验证实际切换、草稿保留和恢复原字体。

- GitHub 工具：设置新增「GitHub」，粘贴细粒度令牌（Contents、Pull requests 读写，Actions 只读）后，在 DeepSeek 项目「⋯」里打开「GitHub 工具」。可列出仓库、浏览目录、读文件、搜索代码；在 sermo/ 开头的工作分支上新建或改写文件（分支不存在时从默认分支创建）、开 PR、查看 Actions 结果并附上失败日志的出错行。永远不写默认分支、不合并、不删除；提交和开 PR 前都会确认。
- 工具记录区分云盘和 GitHub；令牌失效时提示到设置更新。
- 提示词变量：系统提示词和项目指令里可写 {{时间}} {{日期}} {{星期}} {{名字}} {{模型}}（或 time/date/weekday/user/model），发送时替换；不认识的花括号原样保留。
- 告诉角色时间流逝：项目「⋯」新开关，默认关闭。对话第一条消息、或隔了两小时以上再发时，只在这次请求里给最新消息加一句时间提示；连续聊天时什么都不加，也不写进对话记录。
- 联网搜索修复：之前回答模型只拿到网页标题和链接，搜索模型写的总结也被丢掉，所以显得「只看题目」。现在保留搜索总结，并由 App 直接读取排名前 3 个网页的正文（每篇约 3500 字，只读公开 http/https 网页，跳转也受同样限制；需要脚本渲染或拒绝访问的网页读不到）。
- 联网工具：项目「⋯」新开关，默认关闭。打开后模型自己决定是否搜索（web_search）或读取某个链接（web_read），来源显示在回答下方，费用计入用量。
- 「Sermo 说明书」项目：启动时自动创建并固定到侧栏（Flash、不开思考），资料是完整使用说明，随版本自动更新，保留你写的指令；删除后不再自动出现，可在「功能一览」里恢复。
- 设置顶部新增「功能一览」，列出所有功能和入口，不花 token。
- 字体：「阅读与外观」的「宋体阅读」开关改为字体选择：内置宋体、系统字体（苹方）、自定义字体。可导入 .ttf/.otf 的常规和粗体，全局生效，可删除恢复；旧的宋体开关设置会自动沿用。
- 回答排版：支持无序列表（含二级缩进）、有序列表（1. / 1) / 1、）、多级标题、引用、分隔线和表格（按 |:---|:---:|---:| 对齐，太宽时可左右滑动，表格内不画高光）；列表续行归入上一条；代码块里的内容不受影响。高光的每条两处上限跨所有段落和列表计算。不做公式排版。
- 打开联网后，输入框上方不再常驻那行说明文字（会盖住回答）；改为地球按钮自己变成带「联网」字样的药丸。搜索进行时仍显示「正在联网搜索…」。
- 修复自动备份选文件夹后点「打开」没反应：设置页已有一个只认 .json 的文件选择器，SwiftUI 让嵌在里面的文件夹选择器沿用了它的类型。文件夹和字体的选择改为直接调用系统选择器。
- 同步了仓库中 1.5.9 的刷新任务重构（GoogleRefreshTask）及其测试。新增变量、时间提示、GitHub 参数与分支规则、日志摘要、说明书刷新的单元测试。
