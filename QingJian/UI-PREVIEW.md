# 青笺 1.1 界面优先版

版本 1.1.1，构建编号 6。最低系统 iOS 26，主要用于小龙的 iOS 27 手机。

这一版先交付黑白灰界面、系统原生液态玻璃输入栏和导航栏、圆形操作、层叠侧栏，以及随包提供的 Noto Serif SC 宋体风格字体。保留已经修好的字节流聊天，提供模型切换、思考开关、系统提示词、密钥与余额检查、历史搜索、置顶、改名、收藏和 JSON 备份。

消息可长按编辑。编辑和重试都会保存为另一个对话，原记录保留，当前对话顶部可返回原对话。首版暂未提供完整的同屏版本树。草稿按对话保存，保存失败不再作为设置保存成功处理。

本版可调整正文字号、切换宋体/系统字体以及 AI 气泡。相册图片、更多字体导入和壁纸设置尚未加入。

## 验证

沿用原有 SSE 回归测试，新增旧记录兼容、用户消息编辑、AI 消息编辑与重试保留原文测试。云端脚本使用已安装的 Xcode 26 工具链，并从真正的 iOS 模拟器采集首页、聊天、键盘、侧栏、设置、收藏和编辑界面。验证结论以实际测试日志和下载后的安装包核验为准。

模拟器通过 `--ui-preview` 加载虚构演示内容，该模式不读取个人 Key、不请求 DeepSeek、不读写正式记录。普通启动使用真实本机记录与 Key。

字体文件来自 Noto CJK 项目，原文件与 SIL Open Font License 已包含在 Resources。字体 PostScript 名为 NotoSerifSC-Regular。

源码和旧 IPA 保留。安装时沿用原来的证书和 Bundle ID；需要保留的记录先在旧版导出备份。

## 思考过程按需翻译

等回答结束，手动点击思考区域旁的“翻译”。只发送这条消息的思考原文到同一 DeepSeek 服务，使用当前 Key、Flash 模型且关闭思考。翻译结果完整返回后才显示，支持原文、中文、双语切换并随记录和备份保存。查看缓存不会重复请求，译文不会加入正常聊天上下文。翻译请求会产生额外 API 用量；失败、取消或输出截断时不保存不完整的译文。
